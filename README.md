# novosti-feed

Публичная лента выпусков для приложения «Новости». Каждое утро сюда приходит новый выпуск.

- `index.json` — список выпусков, свежий первым.
- `editions/<дата>.json` — выпуск целиком.
- `stories.json` — сюжеты, которые развиваются несколько дней.
- `stats/rates.json` — история курсов для графиков.

Тексты — пересказы новостей со ссылками на первоисточники.
